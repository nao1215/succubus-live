# ノクス 010「これは理解できなくていい、と書かれた昔の Unix のコメント」出典（v8、新規）

確かめ方：「読んだ」は WebFetch で本文、「検索」は検索結果の要約。2026-10-27。

- 「You are not expected to understand this」は Unix 第6版のカーネルの、プロセスの切り替えの所のコメント。PDP-11 の C コンパイラのレジスタの退避のくせに頼っていて、ほかの機械では動かず、第7版で作り直された。リッチーは、読者への挑戦ではなく「This won't be on the exam」の調子の冗談だったと説明（読んだ：Wikipedia の Lions' Commentary の項。リッチー本人の odd.html は今は 410/403 で読めなかった）→ https://en.wikipedia.org/wiki/Lions%27_Commentary_on_UNIX_6th_Edition,_with_Source_Code
- ライオンズの注釈書：1976年に UNSW の授業のノートとして作り、1977年に本に。第7版（1977〜）以降のライセンスで注釈を授業に使えなくなり、世界中の学生がコピーで回した（授業のあとに集まって読んだ話も）。1996年に Peer-To-Peer Communications から正式に出版（読んだ：同上）
- 第6版は1975年：一般知識。
- Linux の INITIAL_JIFFIES のコメント「Have the 32-bit jiffies value wrap 5 minutes after boot so jiffies wrap bugs show up earlier.」（読んだ）。一周するのは32ビットの jiffies の値（64ビットの機械では下の32ビット）で、台詞もそう言うように直した（2026-10-27 二回目のレビュー）→ https://github.com/torvalds/linux/blob/master/include/linux/jiffies.h
- 32ビットのミリ秒は約49.7日で一周（2^32 ms）。Windows 95/98 に49.7日つけっぱなしで止まる不具合があり、1999年に修正が出た（検索：The Register 1999年4月3日ほか。KB216641 の本文は読めなかった）→ https://www.theregister.co.uk/1999/04/03/microsoft_fixes_ie_5_ie/
- 電気グルーヴ「Shangri-La」は1997年3月21日発売のシングル（検索：Wikipedia の写しほか）。ノクスが1997年に人間界に来て最初の給料で買った、店長が口ずさんだ、1999年の iモードの携帯、Pixel 6a、1999年の大晦日に大学の計算機室で夜番：src/bible/likes/nox.yaml の答えと stories。
- 一か月に一回再起動する決まりの会社、月曜は再起動の日：チャットの視聴者の話（作った話）。
