## 追記（2026-10-27 英訳の見直し）
- "1" == 1 は true、"one" == 1 は false（"one" は数にすると NaN）、"1" === 1 は false。node で確かめた。https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Equality 。英訳が文字列を "one"（英単語）にしていて誤りになっていたので、「数字の 1 を文字で書いたもの」に直した。日本語（文字の「1」）は正しい。


## 追記（2026-10-27 深夜、シニアの水準への直し。Codex の指摘）
- os.PathError は「the operation and file path that caused it」を持つ（読んだ、2026-10-27）→ https://pkg.go.dev/os#PathError 。「そのまま返すとどのファイルかが消える」を「ファイル名は残る。何のために読んだかはその場所でしか分からない」に直した（指摘 12）。
- errno（読んだ、2026-10-27）：「The value in errno is significant only when the return value of the call indicated an error」「a function that succeeds is allowed to change errno」→ https://man7.org/linux/man-pages/man3/errno.3.html 。台詞を「まず戻り値、失敗したときだけ errno」に（指摘 14）。
- JavaScript の x == null は null と undefined の両方で true（ECMAScript の IsLooselyEqual）。黙って === に直さず、試験と意図を確かめる（指摘 13）。
- gofmt は字下げにタブ、位置合わせにスペースも使う。Gleam は Erlang の上なら OTP の監督の仕組みを使える、型が勝手に立て直すわけではない。vim は「昔入ったサーバーには vi 系がいた」（指摘 39、60）。
