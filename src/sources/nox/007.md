# ノクス 007「遅いからって確認を一個外したら、何が起きる？」出典（v8）

2026-10-27 夜、前の 003 の「速くするために外した確認」「穴の当番の夜」を分けた。

- CVE-2018-17144：2012年からある「一つの取引で同じ入力を二回使っていないか」の確認を、2017年の 0.14 で速くするために外した。0.14 では assert で落ちるだけ、0.15 の作り直しで assert の見る中身が変わり、条件によっては量を増やせる形に。9月17日 14:57 UTC に匿名の報告、17:47 に Matt Corallo が増やせる方に気づく（台詞は「三時間たたないうちに」）、9月18日に 0.16.3 → 確 https://bitcoincore.org/en/2018/09/20/notice/ （005.md にも同じ項）
- 「組み込みでは assert を本番で消すことも多い」：常連の意見（NDEBUG の一般的な使い方）。
- Heartbleed の公開は2014年4月：一般知識。ノクスの百二十枚の証明書、先輩のプリン、「一言も喋らなかったね」は作った話（src/bible/likes/nox.yaml の sweets_best_ever と stories）。
- npm（2025年9月8日）：qix（Josh Junon）が 2FA の更新を装う釣りのメールで乗っ取られ、chalk・debug など週に二十億を超えるダウンロードのパッケージに暗号資産を盗むコード。数時間で取り下げ → 確（bible の knowledge） https://www.stepsecurity.io/blog/20-popular-npm-packages-compromised-chalk-debug-strip-ansi-color-convert-wrap-ansi 。作者の名前は台詞に出さず、「引っかかるわよ」で被害者を笑わない形にした。
- プリンはとろとろ派、ローソンのプレミアムロールケーキ、エナドリを四本飲んで手が震えた、キシリトールのガム、深夜の自販機はジョージアのブラック：src/bible/likes/nox.yaml。
- 手口（どんな取引を作るか、どんなメールか）は話していない。


## 追記（2026-10-27 英訳の見直し）
- Heartbleed の対処は、漏れたかもしれない鍵の失効と、新しい鍵での証明書の再発行・入れ替え → https://heartbleed.com/ 。日本語の「お客さんの証明書」は顧客のサーバの証明書の意味なので、英訳の client certificates（クライアント認証用の証明書という別の用語）を our customers' certificates に直した。


## 追記（2026-10-27 深夜、シニアの水準への直し。Codex の指摘）
- Bitcoin Core の告知（読んだ、2026-10-27）：0.14 では一つのブロックの中の二重の使用で「an assertion failure and a crash」、0.15 で assert が弱まり「This could allow a miner to inflate the supply」。9月17日 14:57 UTC に報告、17:47 に Matt Corallo が増やせる方に気づく、9月18日 00:24 に 0.16.3 → https://bitcoincore.org/en/2018/09/20/notice/ 。「落ちるだけ」を「同じ入力を二回使う取引が採掘されたブロックに入って届くと assert で落ちる、そういうブロック一つで世界中の機械を落とせたかもしれない、それだけで大きな穴」に（Codex 二回目 R04 でブロックの条件を戻した）、assert の説明を「この条件が成り立つはず、を確かめる約束」に直した（指摘 06）。Bitcoin Core は assert を外して作らない（NDEBUG で作ると止まる作り。一般知識）。
- 確認を外す条件（同じ条件か、どの入口からでも副作用の前か、試験に残す、速くなる量を測る）、穴の夜は分かっている所から塞いで残りを並行して数える、分からない機械は「影響なし」に入れない、ロックファイルは意図の一覧なので実際に配った物も確かめる、Heartbleed の夜は塞ぐ→鍵の作り直し→証明書の入れ替え→古いものの失効（指摘 05、07、36、37）。https://heartbleed.com/
- Codex 二回目 R01：既に本番に入った確認の削除は、何を守る確認かを先に聞き、お金に触るなら今夜当番とリードに知らせて戻すかを決める、に直した。
