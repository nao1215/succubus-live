### Rabbit Run の舞台裏（ギャルが作者の代弁で言う。作者の週報 debimate weeknotes）

- 最初はテトリスのクローン（POP TETRIS）。ゲームはすぐできて、テストプレイで一時間ぐらい遊べた。テトリスがいかに完成されたパズルかを思い知った → debimate/content/weeknotes/2026/09-28/index.md「Tetris クローンを作り、出来が良かったので別ゲーに差し替えている」
- 絵の生成が終わらない（3日 GPU を回し続けても終わらない）。ロゴまで作った頃には「GitHub で公開すると権利者から怒られるのでは」と感じる出来になり、ゲーム部分を差し替えた → 同上（作者の心配であって、怒られたわけではない。台詞は「これ公開して大丈夫かな、って心配になっちゃって」）
- キャラはギャル → 銀髪 → 緑 → 大正ロマンの順に作った → 同上（台詞では「作ってるときの呼び方」として四つの呼び名だけ使った）

### Rabbit Run のゲームの事実（rabbitrun リポジトリ）

- ウサギを左右に動かして壁をよけて進む。スペースのハンマーで画面の壁を全部壊す。マカロン100個で1UP。キャラは道の横で、広い道で余裕、狭いと焦る、ミスで泣く。一周は約3分。ブラウザ（スマホも）で動き、始まる前に約40MBを読み込む。隠しコマンドはキーボードがいる → rabbitrun/README.md
- 表情の枚数：ギャル74、ほかは47〜48 → rabbitrun/README.md の Characters の表
- 選ぶ画面で最初に選ばれているのがギャル（heroID = "gyal"）→ rabbitrun/internal/game/scene_menu.go
- ギャルのコースは「せわしない道」（散らばったブロック、シケイン、柱、スラローム、階段）→ rabbitrun/internal/engine/course_themes.go
- 曲はヴィヴァルディの四季をドラムンベースにしたもの → rabbitrun/internal/sound/audio.go
- 服はピンクのパーカー → rabbitrun/assets/characters/gyal/character.json（outfit_check）
