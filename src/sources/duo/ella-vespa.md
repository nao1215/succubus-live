# エラ×ヴェスパ 001：ヴェスパが法被を直しに来たので、アイドルとメタルのライブの作法を比べた

台詞の主張 → 出典URL。ハチミツ注意報・ミナミ・常連の発言・城の出来事・ヴェスパの2023年の整理番号2番は架空（二人のバイブルの設定）。実在の人物は性的な話題にしていない（下ネタは「搾り取る」＝物販の財布の一つだけで、実在の人に向けていない。ペンライトの「太いの細いの」は 2026-10-27 深夜の直しでやめた）。

## MIX（アイドルのライブの掛け声）
- 標準のMIXは「Tiger! Fire! Cyber! Fiber! Diver! Viber! Jā-jā!」（タイガー、ファイヤー、サイバー、ファイバー、ダイバー、バイバー、ジャージャー）。イントロや間奏で使う → https://en.wikipedia.org/wiki/Wotagei
- 日本語のMIXもあり、「虎」から始まる → 同上。日本語版の全文は一次資料で確かめられなかったので、台詞では「虎、火、から始まる」までにした（晴海の書き込み）。
- エラの「虎、火、電脳、繊維、潜る方、震える方」はエラ自身の直訳（作り）。ジャージャーの意味は資料で見つからなかったので、二人とも「訳せない」扱いにした。

## メタルの角の手（メロイック・サイン）とキツネの手
- ロニー・ジェイムズ・ディオは、人差し指と小指を立てる手をイタリア人の祖母から教わった、悪い目（マロッキオ）をはらうものとし、悪魔の印ではないと語った（2001年の Metal-Rules.com のインタビュー。原文には当たれず、引用で確認） → https://en.wikipedia.org/wiki/Sign_of_the_horns 、https://blabbermouth.net/news/who-came-up-with-rock-n-roll-devil-horns-ronnie-james-dio-or-gene-simmons-doug-aldrich-weighs-in
- 台詞では「お祖母様に教わった、悪い目をはらう手だとおっしゃっていたそうで」と伝聞にした（原インタビュー未読のため）。
- ディオはレインボーの『Rising』（1976）で歌っている（エラのバイブルの tastes）。
- BABYMETALのキツネの手（角の手に似た形）は、最初のシングル「ド・キ・ド・キ☆モーニング」の制作の中でできた → https://en.wikipedia.org/wiki/Doki_Doki_Morning
- ウェンブリー（2016）とビルボード9位（2025）の話は ella/004 で済んでいるので、触れるだけ（出典は src/sources/ella/004.md）。

## 楽章の途中の拍手（モーツァルト）
- 1778年、パリのコンセール・スピリチュエルで交響曲（K.297「パリ」）を初演。第1楽章の途中、喜ばれると見込んで置いた箇所で客が拍手した。最後の楽章を2本のヴァイオリンだけで静かに始め、急に強くした所でも、見込みどおり拍手が来た（1778年7月3日の父への手紙） → https://gregsandow.com/old/mozpar.htm 、https://www.filharmonikusok.hu/en/?p=91395
- 「楽章の間で拍手をしない」は今の慣習で、当時のパリの客は楽章の途中でも拍手した → 同上
- 台詞は「交響曲『パリ』の初演では」（パリで交響曲を初めて演奏した、と誤読されないように。2026-10-27 深夜に直した）。楽章の途中の拍手は今は会場の作法しだい、とエラに言わせた。

## 確かめなかったので書かなかったもの
- 日本語のMIXの全文、ジャージャーの語源。
- 会場ごとのペンライトの長さ・明るさの決まり（会場や公演で違うので、具体的な数字は出さない）。
- 初めてのライブ（エラ1984年のレインボー武道館／ヴェスパ1987年のおニャン子の解散コンサート）の掛け合いは、尺（23分→14分）のため削った。復活させるなら、解散コンサートは1987年9月20日・国立代々木競技場第一体育館（https://www.nikkan-gendai.com/articles/view/geino/378279）、レインボーの武道館は1984年3月（https://progarchives.com/album.asp?id=54880）。
- 整理番号の呼び方は会場と公演で違う。台詞はヴェスパの行く立ち見の現場の話（「私の行く立ち見の現場なら、まず整理番号」「番号順に呼ぶだけ」）にとどめ、締めも「まずチケットの方式を見て。整理番号か、指定席か」にした。
- 緑と黄緑の両方の糸で縫う案は vespa/003 の終わりで「緑ペンラ二年目」が出したもの。エラはそれを縁取りの形にした。
