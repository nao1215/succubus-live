## 確かめたもの（台詞の主張 → 出典）

### マイナンバーカード
- カード本体の有効期限は、18歳以上は発行日から10回目の誕生日、18歳未満は5回目の誕生日。電子証明書は年齢に関係なく発行日から5回目の誕生日 → 第一生命経済研究所 https://www.dlri.co.jp/files/ld/534498.pdf 、江戸川区 https://www.city.edogawa.tokyo.jp/e038/kurashi/mynumber/card/gaiyo/syotetsuduki/koshinyou.html
  - 台詞：モーラは2021年にカードを作ったので、2026年に電子証明書だけ切れる。カード本体はまだ先。
- 更新は有効期限の3か月前からできる → 神戸市 https://www.city.kobe.lg.jp/a53715/20191025.html
- 電子証明書の更新はオンラインではできず、窓口 → 厚生労働省の資料 https://www.mhlw.go.jp/content/12400000/001505560.pdf （検索結果の要約で確認）
- 暗証番号：利用者証明用（数字4桁）は3回、署名用（英数字6〜16桁）は5回続けて間違えるとロック → 大田区 https://www.city.ota.tokyo.jp/seikatsu/koseki_j/koutekikojinninsyo/locked_mynumber-card.html
- 片方の暗証番号が分かれば、コンビニのキオスク端末で、もう片方を初期化できる。両方分からなければ窓口 → 文京区 https://www.city.bunkyo.lg.jp/tetsuzuki/koseki/mynumberseido/mynumbercard/mynumbercard-annsyoubanngou.html 、練馬区 https://www.city.nerima.tokyo.jp/kurashi/mynumber/mynumber_card/ansho/convinience_password.html
  - 台詞：モーラは両方忘れていたので窓口でやり直した（常連の「窓口十二年」が言う）。
- 顔写真は縦4.5cm×横3.5cm、6か月以内、正面・無帽・無背景 → 佐野市の案内 https://www.city.sano.lg.jp/material/files/group/26/mynumber_cardnoshinsei.pdf ほか（自治体の案内。総務省の原文は未確認）

### 健康保険証
- 従来の保険証は2024年12月2日に新規の発行が終わり、2025年12月1日に一律で有効期限を迎えた → 日本医事新報 https://www.jmedj.co.jp/blogs/product/product_27628 ほか
- 期限切れの保険証でも受診できる暫定の扱いは、当初2026年3月末まで。2026年3月19日に上野厚労相が7月末まで延長と表明 → 熊本日日新聞（共同） https://kumanichi.com/articles/1970326
- 2026年6月18日の医療保険部会で7月末で終えると示し、6月22日付の事務連絡で、8月からはマイナ保険証か資格確認書が原則と周知。再延長はしない方針 → 日本医事新報 https://www.jmedj.co.jp/blogs/product/product_28783 、補助金ポータル https://hojyokin-portal.jp/columns/myna_hokensho_zantei （二次資料。厚労省の事務連絡の原文は未読）
  - 台詞：母が「紙の保険証、本当に使えなくなったの？」と聞き、モーラが「8月から」と答え、資格確認書が届いているはずと言う。

### 住基カード・住基ネット
- 住基カードの交付は2003年8月25日から、2015年12月28日まで（西宮市の説明）。マイナンバー制度で2016年1月から発行終了 → 西宮市 https://www.nishi.or.jp/kurashi/koseki/juminkihondaicho/jukinet-keii.html 、山口県の資料
  - 台詞では「2003年から2015年まで」とだけ言う。終わりの日付は自治体の説明なので細かくは言わない。

### 判子
- 2020年11月13日の河野大臣の会見：押印を求めていた手続14,992種類のうち14,909種類（99%以上）を廃止または廃止の方向。残るのは83（印鑑証明が要るもの、登記、銀行の届出印など）→ 内閣府 https://www.cao.go.jp/minister/2009_t_kono/kaiken/20201113kaiken.html
- 婚姻届の押印は2021年9月1日から任意。押印欄は残っている → 杉並区の Q&A https://www.city.suginami.tokyo.jp/documents/10726/situmonn_koninn_1.pdf 、ゼクシィ https://zexy.net/article/app002003003/

### 消せるボールペン
- フリクションボールは日本では2007年10月発売（2006年にフランスで先に発売）→ BCN https://www.bcnretail.com/market/detail/20190227_107862.html 、President Online https://president.jp/articles/-/6641
- 約60℃以上でインキが無色になる、-10℃前後で消した字が戻ることがある、証書類・宛名など消えては困るものには使わない → パイロットの注意書き（丸善ジュンク堂の商品ページ https://www.maruzenjunkudo.co.jp/products/4902505409981 で確認）
- 役所の記入台の「消せるボールペンは使えません」の札は、あるあるとして書いた（特定の役所の規則としては言わない）。
