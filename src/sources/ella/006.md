# エラ 006：日本人はなぜ速弾きギターが好きなのか、とカラオケの採点

台詞の主張 → 出典URL。月下晩餐会・ギル様・城の出来事・常連の発言は架空。2026-10-27 に10〜15分の雑談の形に作り直した（前の版は src/old/episodes-v7/ella/、その出典は同じ所の *.sources.md）。 多くは src/sources/ella/guitar-heroes.md と重なる。

- 「日本人は速弾きが好き」はエラの持論（統計ではないと台詞で断る）。シェンカーの「神」は日本のファンの呼び名（一般知識）。
- ヨナ抜き音階（長音階の4番目と7番目を抜く五音。短調のヨナ抜きもある）と和声的短音階（自然短音階の第7音を半音上げる。イ短調ならラシドレミファソ♯ラ） → https://ja.wikipedia.org/wiki/ヨナ抜き音階 ／ https://en.wikipedia.org/wiki/Minor_scale
- 2026-10-27：二つの音階を「抜く／足す」の逆として並べる説明をやめた（基準の違う音階は引き算・足し算で比べられない）。台詞は、和声的短音階の説明と、ヨナ抜きは別の話、の二つに分けた。イングヴェイが和声的短音階をよく使う、は奏者の全曲についての主張ではなく、先生（常連）の一言の形。 → https://en.wikipedia.org/wiki/Yngwie_Malmsteen
